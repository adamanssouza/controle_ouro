🐍 Sistema de Controle de Ouro

Projeto pessoal desenvolvido em Python para praticar lógica de programação, organização de código e manipulação de dados.

O sistema permite cadastrar pessoas, registrar quantidades de ouro, dias trabalhados e valores recebidos, realizando cálculos e apresentando os resultados de forma organizada.

⚙️ Funcionalidades

- Cadastro de pessoas.
- Registro de ouro em gramas.
- Registro de dias trabalhados.
- Registro de valores recebidos.
- Cálculo do total de ouro por pessoa.
- Cálculo do valor total recebido.
- Cálculo do ganho por dia trabalhado.
- Consulta de todos os cadastros.
- Cálculo dos totais gerais.
- Identificação da pessoa com maior ganho diário.

💻 Tecnologias utilizadas

- Python 3

📚 Conceitos aplicados

Durante o desenvolvimento, foram utilizados conceitos fundamentais da linguagem Python:

- Funções ("def").
- Listas e dicionários.
- Estruturas condicionais ("if", "elif", "else").
- Laços de repetição ("while" e "for").
- Parâmetros e retorno de funções ("return").
- Funções nativas ("sum").
- Manipulação e organização de dados.

▶️ Como executar

1. Tenha o Python instalado em seu computador.
2. Faça o download ou clone este repositório.
3. Abra a pasta do projeto no Visual Studio Code.
4. Execute o arquivo:

python controle_ouro.py

📋 Menu do sistema

O programa possui um menu interativo com as seguintes opções:

1. Cadastrar pessoa.
2. Ver todas as pessoas.
3. Ver total geral.
4. Ver maior valor por dia.
5. Sair.
